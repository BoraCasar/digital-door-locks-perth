# Clean & Minimal Style Guide

## The feeling
Professional security technology rather than a traditional emergency locksmith website.

## Header
- White background.
- Approx. 72–76px tall desktop header.
- Logo left, simple navigation centre/right.
- One dark navy CTA button.
- Plenty of horizontal breathing room.

## Hero
- Background: very light blue-grey or white.
- Desktop: approximately 45% text / 55% image.
- Large dark navy heading, left aligned.
- One short supporting paragraph.
- One strong CTA.
- Photograph should be bright, architectural and tightly art-directed.
- Never overlay large blocks of text on the image.

## Trust strip
- White background.
- Three equal columns on desktop.
- Thin vertical dividers.
- Simple navy line icons.
- Concise benefit text.

## Sections
- Use 72–96px vertical rhythm on desktop.
- Alternate white and very pale surfaces.
- Prefer editorial layouts to repeated floating cards.
- Use cards only where they improve scanning.
- Borders should be subtle; shadows should be rare.

## Type
Suggested:
- Body: Inter, 15–17px desktop.
- H1: 48–56px desktop, 36–40px mobile.
- H2: 30–38px desktop.
- Compact line-height for headings, generous line-height for paragraphs.

## Mobile
- Header around 64–68px.
- Full-width image blocks or carefully cropped images.
- Stack desktop columns.
- Keep CTA buttons easy to tap.
- Use 20–24px page gutters.
